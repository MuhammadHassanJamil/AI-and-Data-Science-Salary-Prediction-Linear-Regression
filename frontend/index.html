🔄 2/3 Training & 1/3 Testing Partition

Following strict assignment guidelines, the 8,000-instance dataset is partitioned into:

  • Training Split (2/3): 5,333 samples used for fitting preprocessing transformations and model coefficients.
  • Testing Split (1/3): 2,667 completely unseen samples used to compute unbiased generalization error.

🎯 10-Fold Cross-Validation

The training set is further evaluated using 10-fold cross-validation ($K=10$). In each fold, 90% of training data is used for fitting while 10% is held out for validation. Repeating across all 10 folds ensures every training record is evaluated out-of-fold, producing reliable RMSE estimates.

🛡️ Leakage-Free scikit-learn Pipeline

All imputations (median for numeric, mode for categorical) and one-hot encodings are fitted strictly inside training folds via ColumnTransformer, ensuring test features never contaminate training state.

💡 Why Linear Regression Fits Exceptionally Well

With an $R^2$ exceeding 0.9260, salary drivers exhibit genuine additive linearity. Regularized linear algorithms eliminate multicollinearity and deliver interpretable coefficients in milliseconds.
